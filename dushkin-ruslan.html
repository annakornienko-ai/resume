Приоритет: 3 из 3 в Manual QA Senior

Душкин Руслан

Ручной QA с API и интеграционным контуром, но слабее остальных manual-кандидатов по требованиям текущего тендера.

Роль: Manual QA Senior
Город: Саратов

Профиль

  • Резюме
  • Скрининг
  • Доп. файл: скрининг (копия)

Комментарии Umbrella IT (14 мая)

  • Дополнительно раскрыт опыт по REST/SOAP, XSD/XML, СМЭВ-интеграциям, Kafka/RabbitMQ/ActiveMQ, тест-кейсам и работе с логами.
  • Уточнено, что есть практический опыт работы с PostgreSQL, Oracle и интеграционными сценариями, но без сильных артефактов и глубоких технических примеров в пакете.
  • Сохраняются ограничения: SQL оценен как ниже среднего, k8s и Linux на прикладном уровне, по доменным политикам и СМЭВ нет глубокой подтвержденной детализации.

Сильные стороны

  • Есть опыт ручного тестирования, интеграционных сценариев и базовое понимание k8s.
  • Ориентируется в API и тест-дизайне.
  • Может подойти как middle-ручник в менее жестком контуре.

Слабые стороны

  • Нет подтверждения высшего образования в клиентском пакете.
  • Слабая глубина по SQL, Wiremock, TLS/SSL и Kafka/RabbitMQ.
  • Не дотягивает до Manual QA Senior по системности, логированию и техническим артефактам.

Дополнительные комментарии

  • Третий номер manual-пула.
  • Слабый кандидат под этот тендер без серьезной переработки материалов.
